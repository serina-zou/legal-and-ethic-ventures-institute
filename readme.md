# Legal & Ethics Ventures Institute Website

**[View current version (v4) →](https://serina-zou.github.io/legal-and-ethic-ventures-institute/v4/)**

Website redesign for the Legal & Ethics Ventures Institute, part of the FloLabs Innovations Group portfolio.

Work done during my UI/UX Design Internship at FloLabs Innovations Group (May–Sep 2026).

**My role:** UI redesign. In the team UX audit of this site and the Space Ventures Institute site, I owned the responsive review of tablet and mobile layouts.

## Shared framework

The site uses the hero, project card and application CTA components I first designed for [MoodChanger](https://github.com/serina-zou/moodchanger). This keeps it consistent with the other sites in the FloLabs portfolio.
